# 防御性表述治理

## 能力定位

本 Skill 与当前写作任务共同使用。当前任务决定正文的研究内容、论证、结构和表达；本 Skill 只管理防御性内容与正文的分离，不提供另一套正文写作方法。

完整读取 [写作治理文件模板](assets/writing-governance.md)。模板中的固定治理边界用于区分防御性内容和正文的实质内容，不作为正文材料。

## 预先治理

新写或继续写作时，优先采用预先治理：

1. 当前项目已有 `writing-governance.md` 时，读取并沿用；没有时，在正文输出目录依据模板创建该文件。
2. 当前写作任务照常形成正文。拟写内容若主要用于保护作者、模型、工具或流程，而不承担正文的实质功能，则不写入正文，改记在治理文件的“当前项目治理事项”中。
3. 治理事项只记录本次真实出现的内容、相关正文对象及作者后续需要掌握的事实，不为保持栏目完整而补造条目。
4. 正文交付不附治理说明。作者要求查看、修改或继续使用治理内容时，提供治理文件。

## 既有文本处理

用户要求处理已经形成的文本时，识别其中的防御性内容，将其转存到治理文件，并从正文移除。防御性内容与实质内容位于同一句时，只调整分离所需的语法连接；正文的事实、判断、条件、论证关系、结构、证据等级和承诺范围保持不变。

## 完成条件

- 正文没有承担作者、模型、工具或流程自我保护功能的内容。
- 治理文件保存了被分离内容及其对作者的参考作用。
- 数学条件、证据范围、真实不确定性、风险信息和必要披露仍在正文中准确表达。
- 本 Skill 没有改变当前写作任务的目标、材料效力和正文形成方法。
